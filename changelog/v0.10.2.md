# v0.10.2 — Derived visual-style defaults + image visual fix

## Why

Field testing v0.10.1 against a real mirrored report surfaced a systematic class of gap: `extractStyleProfile` captured per-type exemplars, but nothing translated their **container chrome** (borders, backgrounds, drop shadows, visual-header/title settings) or **type-specific text objects** (card value labels, slicer header/items, table fonts, page-navigator tab states) into applied styling. Mirrored reports therefore lost borders, callout sizing, slicer text metrics and nav-tab styling unless the agent re-specified each by hand. Separately, `pbir_add_visual` wrote image scaling to a non-existent `general.scaling` property, which can render images broken.

## Changes

1. **`deriveVisualStyleDefaults(profile)`** (exported, `src/styleMirror.ts`): walks `visualExemplars`, unwraps PBIR property expressions (`Literal` `'#324368'`/`3D`/`true`, `solid.color`) into plain theme values, and emits a theme-ready `visualStyles` object:
   - container chrome per type: `border`, `background`, `dropShadow`, `visualHeader`, `title`
   - type-specific objects: card `labels`/`categoryLabels`; slicer `items`/`header`; pivotTable/tableEx `values`/`columnHeaders`/`rowHeaders`/`grid`; pageNavigator `shape`/`outline`/`text`/`layout`
   - a shared `"*"` fallback carrying the consensus border/background/dropShadow for types without exemplars
   Selector-scoped entries (hover/selected states) are skipped — themes only take unselectored defaults.
2. **Profiles now carry `visualStyleDefaults`** — computed at extract time in both the enhanced-PBIR and legacy extractors.
3. **`applyStyleProfile` merges the defaults into the custom theme automatically** (and synthesises a minimal `MirroredStyle.json` theme when the source used only a base theme), so borders/title bars/callouts are picked up by construction. New `visualStylesMerged` flag on the result.
4. **Image visual fix** (`src/helpers/createVisual.ts`): scaling now written as `imageScaling.imageScalingType` with PascalCase `'Fit' | 'Fill' | 'Normal'` — previously an invalid `general.scaling` property that Power BI ignored/renders broken.
5. Tests: `scripts/test-mirror-style.js` 16 → 20 assertions (derived card border/labels, slicer header/items, shared `"*"` chrome, apply-merge without source theme).
