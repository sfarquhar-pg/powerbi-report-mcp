# v0.10.3 — Drillthrough pages importable by Fabric

## Bug

`pbir_create_page` with the `drillthrough` option wrote a legacy `isAllFilter: true` property on the page filter. The Fabric import schema (page 2.1.0 and 2.3.0, `additionalProperties: false`) rejects it — `Report_Import_FailedToImportReport: Property 'isAllFilter' has not been defined` — so any report containing an MCP-authored drillthrough page failed to publish. Found publishing a real drillthrough page; confirmed against the live Fabric importer.

## Fix

Enhanced-PBIR drillthrough declaration:
- the page filter is written with `howCreated: "Drillthrough"` (no `isAllFilter`),
- a `pageBinding` block is added: `{ name: <pageId>, type: "Drillthrough", parameters: [{ name: <property>, boundFilter: <filterName> }] }`.

Verified end-to-end: the corrected shape imports cleanly via `updateDefinition` and the page appears in the right-click Drill through menu.
